# 🚀 week 8 - 객체와 클래스 (Object & Class)

## 1. 객체 지향 프로그래밍 개요
* **절차 지향 vs 객체 지향**
  * **절차 지향**: 프로시저(함수)를 기반으로 순차적으로 실행되는 프로그램 방식입니다.
  * **객체 지향**: 관련 있는 데이터(속성)와 함수(동작)를 하나의 덩어리로 묶어 **객체(Object)**를 만들고, 이 객체들의 상호작용으로 프로그램을 구성합니다.
* **파이썬의 특징**: 파이썬에서는 정수, 문자열, 리스트를 포함한 모든 것이 객체로 구현됩니다.

---

## 2. 핵심 개념
### 💡 클래스(Class)와 객체(Object) / 인스턴스(Instance)
* [cite_start]**객체(Object)**: 속성(Attribute)과 동작(Action)을 가지는 실체입니다.
* [cite_start]**클래스(Class)**: 객체를 생성하기 위한 틀, 청사진(Blueprint) 또는 설계도입니다.
* [cite_start]**인스턴스(Instance)**: 클래스로부터 실제로 만들어진 개별 객체를 의미합니다.

### 🔒 캡슐화(Encapsulation)와 정보 은닉(Information Hiding)
* **캡슐화**: 데이터와 알고리즘을 하나로 묶고 외부에는 공용 인터페이스만 제공하여 세부 구현을 감추는 기법입니다.
* **정보 은닉**: 외부에서 객체의 인스턴스 변수에 직접 접근하여 변경하지 못하도록 제한하는 것입니다.
  * 파이썬에서는 변수 이름 앞에 언더바 `_`를 붙여 private 변수(외부 변경 금지)임을 명시합니다.
  * **접근자(Getters)**와 **설정자(Setters)** 메소드를 통해서만 안전하게 변수에 접근하도록 구현합니다.

## 3. 문법 및 코드 구조

### 기본 클래스 구조 및 멤버 접근
* 클래스는 `class` 키워드로 정의하며, 동작은 메소드로, 속성은 인스턴스 변수로 표현합니다

```python
class Counter:
    # 1. 생성자: 인스턴스 변수 정의 및 초기화
    def __init__(self, initValue=0):
        self.count = initValue  # 인스턴스 변수 생성
        
    # 2. 메소드 정의
    def increment(self):
        self.count += 1

# 객체 생성 및 멤버 접근
a = Counter(10)     # 초기값 10으로 객체 생성
a.increment()       # 메소드 호출 (동작)
print("카운터의 값 =", a.count)  # 인스턴스 변수 접근
```


### 🗝️ 주요 요소 정리
* **__init__() (생성자):** 객체가 생성될 때 자동으로 호출되는 특수 메소드로, 인스턴스 변수를 정의하고 초기화하는 목적으로 사용됩니다. 
* **self:** 현재 호출되어 사용되고 있는 객체 자신을 가리키는 참조 변수입니다. 
* 참조 공유: 파이썬에서 변수는 객체 자체가 아닌 객체의 메모리 주소(참조값)를 저장합니다. 변수를 다른 변수에 대입하면 동일한 객체를 참조하게 됩니다. 
* 클래스 변수: 모든 객체가 공유하는 변수로, 클래스 정의 내부에서 선언하며 모든 인스턴스가 단 하나의 변수를 함께 사용합니다. 상수를 정의할 때도 자주 쓰입니다. 


## 4. 특수 메소드 (Special Methods)
#### 파이썬에는 연산자(+, -, == 등)를 객체에 적용했을 때 자동으로 호출되는 특수 메소드가 있습니다.
* **__add__(self, other):** + 연산자 오버로딩
* **__sub__(self, other):** - 연산자 오버로딩
* **__eq__(self, other):** == 연산자 오버로딩 (두 객체가 같은지 비교)
* **__str__(self):** 객체를 문자열로 표현할 때 호출 (print() 등으로 출력 시 사용)
