## 1. 변수 와 상수
* **변수:** 컴퓨터 메모리 공간에 이름을 붙여 값을 저장하는 곳입니다.
* **상수:** 프로그램이 실행되는 동안 값이 변하지 않는 고정된 값을 의미합니다.

## 2. 자료형
#### 파이썬은 변수에 저장되는 값의 종류에 따라 자료형이 자동으로 결정됩니다.
* **정수형 ( `int`):** 소수점이 없는 양수, 음수, 0 (예: `10`, `-5`)
* **실수형 (`float`):** 소수점이 포함된 숫자 (예: `3.14`, `-0.5`)
* **문자열 (`str`):** 큰따옴표(`" "`)나 작은따옴표(`' '`)로 감싼 텍스트 (예: `"Hello"`)

## 3. 수식과 연산자
* **배정(할당) 연산자 (`=`):** 우변의 값을 좌변의 변수에 저장합니다.
* **산술 연산자:**
  * `+` (더하기), `-` (빼기), `*` (곱하기), `/` (나누기 - 결과는 항상 실수)
  * `//` (몫 연산자): 나눗셈의 몫(정수)만 구함
  * `%` (나머지 연산자): 나눗셈의 나머지 구함
  * `**` (거듭제곱 연산자): 좌변을 우변만큼 제곱함 (예: `10 ** 3`은 1000)
* **연산자 우선순위:** 거듭제곱(`**`) ➡️ 곱셈/나눗셈(`*`, `/`, `//`, `%`) ➡️ 덧셈/뺄셈(`+`, `-`) 순으로 계산되며, 괄호 `()`가 있으면 최우선으로 계산됩니다.

## 4. 콘솔 입력과 출력 (I/O)
* **`print()` 함수 (출력):** 화면에 변수나 연산 결과를 출력합니다. 쉼표(`,`)를 사용하면 여러 값을 공백으로 구분하여 한 줄에 출력할 수 있습니다.
* **`input()` 함수 (입력):** 사용자로부터 키보드로 입력을 받습니다.
* **자료형 변환 (Type Casting):** 숫자를 입력받아 계산에 사용하려면 문자열을 숫자로 변환해야 합니다.
  * `int()`: 문자열을 정수로 변환 (예: `int(input("정수 입력: "))`)
  * `float()`: 문자열을 실수로 변환 (예: `float(input("실수 입력: "))`)
