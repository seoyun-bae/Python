# 🚀 Week 1: 파이썬(Python) 프로그래밍 소개

## 1. 프로그래밍 언어와 통역사
* **기계어:** 컴퓨터는 0과 1로 이루어진 '기계어'만을 이해할 수 있으며, 사람의 언어를 직접 이해하지 못합니다
* **컴파일러 / 인터프리터:** 사람이 프로그래밍 언어(C, Java, Python 등)로 코드를 작성하면, 이를 컴퓨터가 이해할 수 있는 기계어로 바꾸어주는 통역사 역할을 하는 소프트웨어입니다.

## 2. 파이썬 실행 모드
* **대화형 모드(Interactive Mode):** 콘솔(프롬프트 `>>>` 또는 IPython 콘솔)에서 한 줄씩 명령어를 입력하고, <kbd>Enter</kbd>를 누르는 즉시 실행 결과가 나타나는 모드입니다.
* **스크립트 모드(Script Mode):** 작성한 코드를 확장자가 `.py`인 파일로 저장한 후, 파일 전체를 한 번에 실행하는 모드입니다. 코드가 복잡해질 때 주로 사용됩니다.

## 3. 기본 문법 및 함수
* **`print()` 함수:** 텍스트나 연산 결과를 화면(콘솔)에 출력할 때 사용하는 내장 함수입니다.

```python

  print("Hello World!")  # 문자열 출력
  print("결과값은", 10, "입니다.")  # 여러 개의 값을 차례대로 출력

```
