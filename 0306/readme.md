## 1. 컴퓨터와 프로그램 기본 개념
* [cite_start]**프로그램(Program):** 컴퓨터가 특정한 작업을 수행할 수 있도록 인간이 작성한 상세한 명령어(Instruction)들의 리스트(작업지시서)입니다[cite: 3, 4, 83].
* [cite_start]**하드웨어와 소프트웨어:** 하드웨어는 컴퓨터 시스템의 물리적인 부품이며, 소프트웨어는 이를 유연하게 제어하는 프로그램입니다[cite: 2, 3]. [cite_start]소프트웨어를 교체함으로써 하나의 하드웨어(컴퓨터)로 문서 작성, 게임 등 다양한 작업을 수행할 수 있습니다[cite: 2].

## 2. 프로그래밍 언어와 통역사
* [cite_start]**기계어:** 컴퓨터는 0과 1로 이루어진 '기계어'만을 이해할 수 있으며, 사람의 언어를 직접 이해하지 못합니다[cite: 13, 15].
* [cite_start]**컴파일러 / 인터프리터:** 사람이 프로그래밍 언어(C, Java, Python 등)로 코드를 작성하면, 이를 컴퓨터가 이해할 수 있는 기계어로 바꾸어주는 통역사 역할을 하는 소프트웨어입니다[cite: 14, 15, 16].

## 3. 파이썬(Python)의 특징
* [cite_start]1991년 **귀도 반 로섬(Guido van Rossum)**이 개발한 대화형 프로그래밍 언어입니다[cite: 17].
* [cite_start]**간결성과 생산성:** 문법이 매우 간결하고 직관적이어서 코드를 빠르게 작성할 수 있고, 가독성이 뛰어납니다[cite: 18].
* [cite_start]**인터프리터 언어:** 소스 코드를 한 줄씩 즉시 실행하고 결과를 확인할 수 있어 초보자가 배우기에 매우 유리합니다[cite: 20].
* [cite_start]**풍부한 라이브러리:** 빅데이터, 인공지능, 웹 크롤링 등 다양한 분야에 즉시 활용할 수 있는 강력한 라이브러리(패키지) 생태계를 가지고 있습니다[cite: 21, 22].

## 4. 파이썬 실행 모드
* [cite_start]**대화형 모드(Interactive Mode):** 콘솔(프롬프트 `>>>` 또는 IPython 콘솔)에서 한 줄씩 명령어를 입력하고, <kbd>Enter</kbd>를 누르는 즉시 실행 결과가 나타나는 모드입니다[cite: 46, 83].
* [cite_start]**스크립트 모드(Script Mode):** 작성한 코드를 확장자가 `.py`인 파일로 저장한 후, 파일 전체를 한 번에 실행하는 모드입니다[cite: 46, 54, 84]. [cite_start]코드가 복잡해질 때 주로 사용됩니다[cite: 46].
