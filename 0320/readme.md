# 🚀 Week 3: 조건문

## 1. 제어문과 제어 구조
* **순차 구조:** 명령어들이 순서대로 실행되는 기본 구조
* **선택 구조:** 조건에 따라 서로 다른 명령어가 실행되는 구조 (조건문)
* **반복 구조:** 조건이 만족될 때까지 명령어를 되풀이하는 구조 (반복문)

## 2. 관계 연산자
#### 두 값을 비교하여 참(`True`) 또는 거짓(`False`)을 반환하는 연산자입니다.

## 3. 논리 연산자
여러 개의 조건을 조합하여 복잡한 조건을 만들 때 사용합니다.
* `and` (논리곱): 두 조건이 **모두 참**이어야 참 (예: `x > 0 and x < 10`)
* `or` (논리합): 두 조건 중 **하나라도 참**이면 참
* `not` (논리부정): 조건의 결과를 반대로 뒤집음 (참 ➡️ 거짓, 거짓 ➡️ 참)

### 기본 구조
```python
if 조건식:
    # 조건식이 참(True)일 때 실행할 코드 (들여쓰기 필수)
    print("참입니다.")
else:
    # 조건식이 거짓(False)일 때 실행할 코드 (들여쓰기 필수)
    print("거짓입니다.")
```

## 4. 다중 조건문 (연속 if-else / 중첩 if-else)
* **연속 if-else 문 (if-elif-else):** 여러 조건 중 하나를 선택해야 할 때 사용하며, 제한 없이 elif를 추가할 수 있습니다.

```python
score = 85
if score >= 90:
    print("A 학점")
elif score >= 80:
    print("B 학점")
else:
    print("C 학점 이하")
```
