# 🚀 Week 3: 조건문 (Conditional Statements)

## 1. 제어문과 제어 구조
프로그램의 기본 실행 흐름은 위에서 아래로 순차적으로 진행되지만, 상황에 따라 실행 순서를 변경해야 할 때 **제어문**을 사용합니다.
* **순차 구조:** 명령어들이 순서대로 실행되는 기본 구조
* **선택 구조:** 조건에 따라 서로 다른 명령어가 실행되는 구조 (조건문)
* **반복 구조:** 조건이 만족될 때까지 명령어를 되풀이하는 구조 (반복문)

## 2. 관계 연산자 (Relational Operators)
두 값을 비교하여 참(`True`) 또는 거짓(`False`)을 반환하는 연산자입니다.
* **주의:** `=`는 배정(할당) 연산자

## 3. 논리 연산자 (Logical Operators)
여러 개의 조건을 조합하여 복잡한 조건을 만들 때 사용합니다.
* `and` (논리곱): 두 조건이 **모두 참**이어야 참 (예: `x > 0 and x < 10`)
* `or` (논리합): 두 조건 중 **하나라도 참**이면 참
* `not` (논리부정): 조건의 결과를 반대로 뒤집음 (참 ➡️ 거짓, 거짓 ➡️ 참)

## 4. if-else 문의 기본 문법 및 블록(Block)
코드의 영역을 구분하기 위해 **들여쓰기(Indentation)**를 반드시 사용해야 합니다.
들여쓰기가 같은 문장들은 하나의 **블록(Block)**으로 묶입니다.

### 기본 구조
```python
if 조건식:
    # 조건식이 참(True)일 때 실행할 코드 (들여쓰기 필수)
    print("참입니다.")
else:
    # 조건식이 거짓(False)일 때 실행할 코드 (들여쓰기 필수)
    print("거짓입니다.")
```

## 5. 다중 조건문 (연속 if-else / 중첩 if-else)
* **연속 if-else 문 (if-elif-else):** 여러 조건 중 하나를 선택해야 할 때 사용하며, 제한 없이 elif를 추가할 수 있습니다.

```python
score = 85
if score >= 90:
    print("A 학점")
elif score >= 80:
    print("B 학점")
else:
    print("C 학점 이하")
```
* **중첩 if 문 (Nested if):** 조건문 안에 또 다른 조건문을 포함하는 구조입니다. 더욱 세부적인 조건을 판별할 때 유용합니다.

## 6. 주의해야 할 점 (오류 예방)
