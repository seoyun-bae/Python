## 1. 리스트의 개념
* **리스트:** 항목(Item)들을 순서대로 저장하는 컨테이너(자료구조)입니다.
* 파이썬의 리스트는 서로 다른 자료형(정수, 문자열, 불리언 등)을 하나의 리스트 안에 섞어서 저장할 수 있습니다.

```python
# 리스트 생성 예시
shopping_list = ["apple", "banana", "cherry"]
mixed_list = [1, "Hello", 3.14, True]
empty_list = []
```

## 2. 인덱싱과 슬라이싱
* **인덱싱:** 리스트의 특정 위치에 있는 요소에 접근합니다. (인덱스는 0부터 시작, 음수 인덱스는 뒤에서부터 역순)
* **슬라이싱:** 리스트의 일부분을 잘라내어 새로운 리스트를 만듭니다. list[start:end] 구조이며 end 인덱스는 포함되지 않습니다.
```python
numbers = [10, 20, 30, 40, 50]

print(numbers[0])   # 10 (첫 번째 요소)
print(numbers[-1])  # 50 (마지막 요소)
print(numbers[1:4]) # [20, 30, 40] (인덱스 1부터 3까지)
```

## 3. 리스트 연산 및 주요 메서드

### ➕ 요소 추가 및 연결
* **append(x):** 리스트의 맨 끝에 항목 x를 추가합니다.
* **insert(index, x):** 지정된 인덱스 위치에 항목 x를 삽   입합니다.
* **extend(list2) 또는 + 연산자:** 두 리스트를 하나로 합칩니다.

### ➖ 요소 삭제
* **pop(index):** 지정한 인덱스의 항목을 삭제하면서 그 값을 반환합니다. (인덱스 생략 시 맨 뒤 항목 삭제)
* **remove(x):** 리스트에서 값이 x인 첫 번째 항목을 찾아 삭제합니다.
* **clear():** 리스트의 모든 요소를 제거합니다.

### 🔍 탐색 및 정렬
* **index(x):** 항목 x가 위치한 인덱스를 반환합니다.
* **count(x):** 리스트에 포함된 항목 x의 개수를 반환합니다.
* **sort():** 리스트의 요소를 오름차순으로 정렬합니다. (reverse=True 설정 시 내림차순)
* **reverse():** 리스트의 요소 순서를 반대로 뒤집습니다.
